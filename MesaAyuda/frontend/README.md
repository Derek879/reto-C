# Mesa de Ayuda · Frontend Angular

Angular 18 con componentes standalone, signals, control flow (`@if`, `@for`), formularios reactivos y rutas con carga diferida.

```bash
npm install
npm start   # http://localhost:4200, redirige /api a la API en http://localhost:5030 (proxy.conf.json)
```
